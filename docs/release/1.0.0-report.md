# ContainerDesk 1.0.0 release report

**Status: blocked; this is an evidence report, not release approval.** A local integrated candidate was built and verified at commit `fbb9dff`. It remains an unsigned, non-hardened development artifact that Gatekeeper rejects; missing acceptance, Developer ID and notarization evidence still block release.

- Host: macOS 27.2.1 (26B131), arm64, 12 CPUs.
- Xcode: 27.2 (27B52).

## Release blockers

1. No Developer ID Application signing identity is installed; the signing credential ticket remains open. Do not publish this ad-hoc artifact.
2. No notarization result or stapled ticket exists; the release automation/notarization path remains open.
3. No macOS 26 verification environment or pass exists. Do not claim macOS 26 support or verified compatibility.
4. E-01 did not run from a clean Runtime-free state and has no complete walkthrough recording.
5. The E-07 friendly registry error fix has unit and UI coverage but has not been retested in an installed build from the integrated source.
6. The full UI-test scheme has no clean integrated-candidate result. The isolated launch-test target on `fbb9dff` reproduced the host application lookup failure; see the [captured launch-test log](evidence/e1-integrated-launch-tests-2026-11-16.log).
7. E-14 Runtime reinstall/plugin-removal recovery and E-17 sleep/wake remain unrun.
8. E-16 did not establish that ContainerDesk quit; the app window remained available after the attempted quit actions.
9. T-C13 remains in progress: the full Accessibility Inspector audit, remaining product findings, keyboard-only flow, full VoiceOver coverage, Reduce Motion setting, and automatic live-status announcements are not complete. The user reported tested VoiceOver controls and flows as usable; these reports do not replace the outstanding audit.
10. T-A3 live reuse-map validation and its requested standards/spec review remain open. Parallel-subagent review is paused at the user's direction.
11. T-A4 has only a 61-second idle sample from an installed build with unknown source revision. Cold-launch timing and chatty-log polling were not measured, so NFR-10 budgets remain unset; see the [partial T-A4 evidence](evidence/a4-idle-measurement-2026-11-16.md).

This report does not call the release public, notarized, signed with Developer ID, or macOS 26-verified.
